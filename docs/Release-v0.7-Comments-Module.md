# Release v0.7 - Comments Module

## 1. Release Summary

v0.7 introduces the Calibre Comments module.

This module supports a controlled workflow for enriching the standard Calibre Comments field with structured, source-aware curator comments.

Workflow:

    Export -> Generate Proposed Comments -> Dry Run -> Summary -> HTML Review -> Apply -> Verify

## 2. Major Features

### Comments source export

Added comments-specific export support through:

    scripts/Export-CalibreBatchForComments.ps1

Supported selection methods include:

- Calibre search strings
- explicit Calibre IDs
- optional library path override

### Comments dry run

Added comments validation and safety checking through:

    scripts/Test-CommentsDryRun.ps1

The dry run validates:

- required fields
- proposed comments presence
- supported template profile
- supported comments mode
- confidence value
- manual review flag
- source notes
- blocked HTML
- current comments hash
- current title and author state

### Comments summary

Added dry-run summary reporting through:

    scripts/Write-CommentsSummary.ps1

### HTML review

Added visual review page generation through:

    scripts/Write-CommentsReviewHtml.ps1

The review page supports visual inspection before apply.

### Comments apply

Added comments apply support through:

    scripts/Invoke-CommentsApply.ps1

The apply script writes to the standard Calibre Comments field.

The apply script requires:

- clean dry-run CSV
- zero blocked rows
- matching current comments hash
- matching current title and author state
- confirmation phrase before write

### Comments verify

Added comments verification support through:

    scripts/Test-CommentsVerify.ps1

The verify script confirms current Calibre comments match the expected post-apply stored hash.

## 3. Managed Comments Strategy

Generated comments include a durable marker:

    <p><b>Generated By:</b> Calibre Metadata Toolkit Comments Module v0.7</p>

This marker allows generated-only comments to be identified and replaced later.

When original comments exist, generated comments are prepended above:

    <hr/><h3>Original Comments</h3>

This preserves original publisher-style comments while allowing future generated comments to be replaced cleanly.

## 4. Apply Method

The apply script originally used direct `--field comments:<html>` writes.

Testing showed that this method was fragile for long generated HTML containing quotes, spaces, and punctuation.

v0.7 now writes comments using a temporary OPF file:

1. export current metadata using `calibredb show_metadata --as-opf`
2. replace or insert `<dc:description>`
3. write a temporary OPF file
4. apply it using `calibredb set_metadata <CalibreId> <temp.opf>`
5. delete the temporary OPF file
6. re-read the Calibre record
7. store the observed post-write comments hash

## 5. Tested States

v0.7 was tested against:

- blank comments
- unmanaged existing comments
- existing generated-only comments
- generated comments with preserved original comments
- mixed-state batch apply
